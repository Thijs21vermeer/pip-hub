Pip op de Google Hub

Even laden…

Werkt in Chrome op Android of op je Mac, op hetzelfde wifi als de Google Hub. Kies na het tikken je Google Hub in de lijst.

Huisgenoten

Wie kan op de Google Hub een taak afvinken? Een wijziging gaat meteen naar Pip als die draait, en anders bij de volgende start.

    Voerraad koppelen

    Maak in Voerraad een koppelcode (Instellingen → Huishouden → Scherm in huis) en plak hem hier. De code blijft alleen op dit apparaat en gaat bij elke start mee naar de Google Hub.

    Kattenbak koppelen

    Plak de kattenbak-code. Die staat op je Mac in ~/.config/pip/kattenbak-code.txt. Ook deze code blijft alleen op dit apparaat en gaat bij elke start mee naar de Google Hub.
