Pip op de Hub

Even laden…

Werkt in Chrome op Android of op je Mac, op hetzelfde wifi als de Hub. Kies na het tikken je Nest Hub in de lijst.

Huisgenoten

Wie kan op de Hub een taak afvinken? Een wijziging gaat meteen naar Pip als die draait, en anders bij de volgende start.

    Voerraad koppelen

    Maak in Voerraad een koppelcode (Instellingen → Huishouden → Scherm in huis) en plak hem hier. De code blijft alleen op dit apparaat en gaat bij elke start mee naar de Hub.
